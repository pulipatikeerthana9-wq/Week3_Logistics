# Week 3 – Logistics Data Analysis and Visualization

## Project Overview

This project performs advanced data analysis and visualization using a simulated logistics dataset containing 3,000 shipments and 19 variables.

## Objectives

* Analyze shipment and delivery performance.
* Examine transportation costs and delivery times.
* Compare logistics performance across regions and service types.
* Identify trends and potential operational bottlenecks.
* Generate visualizations and statistical summaries.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Pytest

## Project Components

* Data simulation and preprocessing
* Exploratory data analysis
* Statistical analysis
* Eight data visualizations
* Automated tests
* Final project report

## Important Note

The dataset is simulated for educational purposes. The results do not represent actual company records.
